What This System Is

This is a governed content production system — a set of rules, knowledge files, and skill definitions that lets an AI agent produce consistent, on-brand Floras sales and marketing materials from a short brief. Built so every team member can generate recognisable Floras assets in minutes.

Folder Structure

Colours, typography, tone, currency rules. skills/ ├ presentation.mdSales presentation rules — structure, slide design, tone. ├ email.mdSales email rules — four types, length constraints, formatting. ├ one-pager.mdOne-pager & proposal rules — A4 layout, section structure. └ social-post.mdLinkedIn content rules — five post types, no hype, no emojis.
How to Use It

Every generation follows this exact order. Never skip or reorder.

  1. Read SKILL.md — orient yourself to the system structure and rules.
  2. Read style-guide.md — load the brand source of truth before generating anything.
  3. Load the relevant skill file — match artifact type to its skill file (presentation, email, one-pager, or social).
  4. Collect the brief — confirm minimum required inputs. If missing, mark [NEEDS INPUT] and ask. Never invent.
  5. Generate the artifact — apply all brand rules from the style guide and structural rules from the skill file.
  6. Run and display the consistency check — five questions, and show results visibly.
Marks to Watch For

The system uses three tags in outputs. If any are present before shipping, stop.

[NEEDS INPUT]
Missing Information
A required input was not in the brief.
Do: Provide the missing detail.
[NEEDS PROOF]
Unverifiable Claim
The system cannot verify a claim or figure.
Do: Supply a source, rewrite as a mechanism, or remove.
[ILLUSTRATIVE EXAMPLE]
Constructed Scenario
A plausible example built to demonstrate how Floras works — not a real client story.
Do: Label clearly. Replace with a real case study if one exists. Keep if accurate and representative.
